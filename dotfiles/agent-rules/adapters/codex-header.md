# AGENTS.md

Global operating rules for Codex on this user's machines (macOS laptop and the
Ubuntu home server).

A repository's own `AGENTS.md` outranks this file wherever the two disagree.
This file carries no project-specific contracts; those live with their project.

Load a runbook only when the decision in front of you actually needs it:

- `~/.codex/runbooks/execution-policy.md` — PR state and project memory, spec
  drift and retired attempts, planning shape, the long form of anomaly triage.
- `~/.codex/runbooks/gpt-webai-pro.md` — operating the ChatGPT Pro slot daemon.
- `~/.codex/runbooks/gptpro-review.md` — the gptpro-review stack.
